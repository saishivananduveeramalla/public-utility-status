About the Public Utility Status Project

An end-to-end responsive web portal engineered for the Essentials of Web Programming (EWP) Lab external examination, demonstrating frontend standards, asynchronous APIs, XML validation, and Angular architecture.

Project Title: Public Utility Status Portal
Course: Essentials of Web Programming (EWP) Lab
Target City (Sample): Greater Hyderabad Municipal Area (GHMC)
Architecture: Single Page Application (SPA) with Angular & TypeScript

1. Project Objective & Problem Statement

In urban metropolises such as Hyderabad, citizens regularly encounter essential utility disruptions ranging from unscheduled electricity feeder outages and water pipeline leakages to public transit delays and overflowing garbage bins. Traditionally, each municipal agency operates isolated grievance mechanisms, leaving citizens confused about where to report issues and verify restoration schedules.

The Public Utility Status application solves this problem by delivering a unified, citizen-facing portal that aggregates operational statuses across six vital public utility sectors:

1. Electricity (TSSPDCL)
2. Water Supply (HMWSSB)
3. Public Transportation (Metro & TSRTC)
4. Internet Services (T-Fiber & Broadband)
5. Garbage Collection (GHMC Swachh Waste)
6. Road Maintenance (CRMP Engineering)

2. Mandatory Technologies Implementation

HTML5

HTML5

Provides semantic page structure using <header>, <nav>, <main>, <section>, <article>, <footer>, custom form controls, and accessible HTML5 validation attributes.

CSS3

CSS3

Responsive Flexbox and CSS Grid layouts with a light civic palette (Blue, Green, White), custom status badges (Operational, Maintenance, Disruption), card hover animations, and media queries for desktop and mobile form factors.

JS

JavaScript (ES6+)

Modern asynchronous execution with async/await, browser localStorage management for persistent grievance records, and the DOMParser API for native XML document traversal.

XML

XML & DTD

Structured data representation in utilities.xml validated against formal element declarations and grammar rules in utilities.dtd. Demonstrates document typing and markup separation.

FETCH

Fetch API

Asynchronous data loading using native fetch() for both JSON (response.json()) and XML (response.text()), as well as a simulated method: "POST" with JSON request payload headers.

TS

TypeScript

Strongly typed models and interfaces (Utility, Complaint, Announcement, DashboardStats) with compile-time type checking and zero tolerance for arbitrary any usage.

NODE • EXPRESS

Node.js & Express.js Backend

Lightweight REST API running on port 3000. Provides endpoints for GET /api/utilities, GET /api/announcements, and POST /api/complaints with CORS enabled for Angular.

NG

Angular Framework

Component-based architecture with Standalone Components, reactive Signals (signal, computed), Reactive Forms with custom regex validation (10-digit mobile, valid email), client-side SPA routing (provideRouter), and Singleton Services with Dependency Injection.

4. How this Portal Helps Citizens

Proactive Awareness

Citizens can anticipate scheduled maintenance and power/water shutdowns before they occur, allowing prior planning.

Frictionless Grievances

No waiting on congested toll lines. Citizens report outages with validated details and immediately receive a tracking ticket.

Transparent Progress

Real-time grievance tracking with milestones (Submitted → In Progress → Resolved) builds civic accountability.

5. Project Limitations & Future Scope

Current Academic Limitations

  • Demonstration Data: All utility records and status updates represent simulated Hyderabad conditions for college demonstration.
  • Local Browser Storage: Registered grievances are saved in browser localStorage; they do not write to live government SQL/NoSQL databases.
  • Mocked Fetch POST: Grievance POST submission uses a client-side simulated REST endpoint adhering to the EWP syllabus without requiring an external backend server.

Future Production Enhancements

  • Government API Gateways: Integration with official SCADA telemetry from TSSPDCL and HMWSSB smart flow meters.
  • GIS Map Visualization: Interactive geospatial mapping showing outage polygons, water supply feeder lines, and live GPS bus tracking.
  • Automated SMS & WhatsApp Alerts: Push notifications dispatched to registered mobile numbers whenever ticket status changes.
  • Image Evidence Uploads: Ability for citizens to photograph broken poles or open sewage and upload images with geo-tag metadata.
